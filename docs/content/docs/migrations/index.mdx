<Callout title="Supported upstream boundary" type="warn">
  Upstream Komodo `v2.3.2` is the last supported upstream migration source. Migration from later upstream releases is not promised because the projects diverged after the hard fork.
</Callout>

Every migration must start with backups. Keep the old configuration and data available until the new version passes the guide's verification steps and you have rehearsed the rollback.

- [Migrate v2 to v3](/migrations/v2-to-v3)
- [Migrate v1 to v2](/migrations/v1-to-v2)

Release notes and changelogs are published only on [GitHub Releases](https://github.com/neurekadev/komodo/releases).
