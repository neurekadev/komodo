Komodo Core exposes an RPC-like HTTP API to read data, write configuration, and execute actions.
There are typesafe clients available in
[**Rust**](/reference/api-and-client-libraries#rust-client) and [**Typescript**](/reference/api-and-client-libraries#typescript-client).

The fork-generated client sources live under `client/core` in the Komodo
repository. They are not currently published by this fork. Packages named
`komodo_client` on crates.io and NPM are upstream artifacts and may not match
the fork API.

## Rust Client

Build the Rust client from `client/core/rs` in the same Git revision as Core.

```rust
let komodo = KomodoClient::new("https://komodo.example.com", "your_key", "your_secret")
  .with_healthcheck()
  .await?;

let stacks = komodo.read(ListStacks::default()).await?;

let update = komodo
  .execute(DeployStack {
    stack: stacks[0].name.clone(),
    stop_time: None
  })
  .await?;
```

## Typescript Client

Build the TypeScript client from `client/core/ts` in the same Git revision as
Core.

```ts
import { KomodoClient, Types } from "komodo_client";

const komodo = KomodoClient("https://komodo.example.com", {
  type: "api-key",
  params: {
    key: "your_key",
    secret: "your secret",
  },
});

// Inferred as Types.StackListItem[]
const stacks = await komodo.read("ListStacks", {});

// Inferred as Types.Update
const update = await komodo.execute("DeployStack", {
  stack: stacks[0].name,
});
```


## Execute Terminal

The `execute_terminal` API method allows you to run a command on a terminal and stream the output back over HTTP. This is useful for:

- **Actions** — TypeScript scripts can call `execute_terminal` on the Komodo client to run commands on any server or container and process the output programmatically.
- **Automation** — integrate terminal command execution into external tools via the REST API.

The TypeScript client provides convenience methods for each target type. All methods accept optional `callbacks` with `onLine` (called per output line) and `onFinish` (called with the exit code).

```typescript
// Server terminal
await komodo.execute_server_terminal({
  server: "my-server",
  terminal: "automation",
  command: "df -h",
  init: { command: "bash", recreate: "DifferentCommand" },
}, {
  onLine: (line) => console.log(line),
  onFinish: (code) => console.log("Exit code:", code),
});

// Container terminal
await komodo.execute_container_terminal({
  server: "my-server",
  container: "my-container",
  terminal: "debug",
  command: "cat /var/log/errors.log",
  init: { command: "sh", mode: "Exec", recreate: "Never" },
});

// Stack service terminal
await komodo.execute_stack_service_terminal({
  stack: "my-stack",
  service: "web",
  terminal: "debug",
  command: "nginx -t",
  init: { command: "sh" },
});

// Deployment terminal
await komodo.execute_deployment_terminal({
  deployment: "my-deployment",
  terminal: "check",
  command: "node --version",
  init: { command: "sh", recreate: "Always" },
});
```
