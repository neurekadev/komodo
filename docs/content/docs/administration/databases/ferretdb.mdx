---
title: FerretDB
description: Install Komodo using PostgreSQL-backed FerretDB.
---


Choose FerretDB when you want PostgreSQL-backed storage or MongoDB cannot run on your host. You need Docker Engine with Compose and an HTTPS reverse proxy that can reach port `9120`.

## Install

1. Create an installation directory with `mkdir -p komodo && cd komodo`.
2. Save the examples below as `compose.yaml` and `.env`.
3. Replace every `REPLACE_WITH_*` value. Use independently generated passwords and secrets (`openssl rand -hex 32`), keep the `${...}` references, and run `chmod 600 .env`. The database password must be URL-safe.
4. Run `docker compose -p komodo config --quiet`, then `docker compose -p komodo up -d`.
5. Point your HTTPS proxy at port `9120`, open `KOMODO_HOST`, and sign in with your administrator credentials.
6. Open **Servers → Local** and confirm **OK**.

Periphery controls the Docker host, including its named volumes. Review [permissions](/administration/users-groups-permissions) before sharing access.

## compose.yaml

```yaml title="compose.yaml"
services:
  komodo:
    image: ghcr.io/neurekadev/komodo-core:${COMPOSE_KOMODO_IMAGE_TAG:-3}
    container_name: komodo
    depends_on: [komodo-ferretdb]
    env_file: [.env]
    networks:
      komodo:
        aliases: [core, komodo-core]
    ports:
      - "9120:9120"
    volumes:
      - data:/data
      - backups:/backups
    restart: unless-stopped
    init: true
    command: [core-compose]

  komodo-postgres:
    image: ghcr.io/ferretdb/postgres-documentdb:17
    container_name: komodo-postgres
    env_file: [.env]
    networks:
      komodo:
        aliases: [postgres]
    volumes:
      - postgres-data:/var/lib/postgresql/data
    restart: unless-stopped
    labels:
      komodo.skip: "true"

  komodo-ferretdb:
    image: ghcr.io/ferretdb/ferretdb:2
    container_name: komodo-ferretdb
    depends_on: [komodo-postgres]
    env_file: [.env]
    networks:
      komodo:
        aliases: [ferretdb, komodo-database]
    volumes:
      - ferretdb-state:/state
    restart: unless-stopped
    labels:
      komodo.skip: "true"

  komodo-periphery:
    image: ghcr.io/neurekadev/komodo-periphery:${COMPOSE_KOMODO_IMAGE_TAG:-3}
    container_name: komodo-periphery
    depends_on: [komodo]
    env_file: [.env]
    networks:
      komodo:
        aliases: [periphery]
    volumes:
      - data:/data
      - /var/run/docker.sock:/var/run/docker.sock
      - ${PERIPHERY_DOCKER_VOLUME_ROOT:-/var/lib/docker/volumes}:${PERIPHERY_DOCKER_VOLUME_ROOT:-/var/lib/docker/volumes}
      - /proc:/proc
    restart: unless-stopped
    init: true
    command: [periphery-compose]

networks:
  komodo:
    name: komodo

volumes:
  postgres-data:
  ferretdb-state:
  data:
  backups:
    labels:
      komodo.file-manager.excluded: "true"
```

## .env

```dotenv title=".env"
KOMODO_HOST=https://REPLACE_WITH_HOST


KOMODO_DATABASE_USERNAME=komodo
KOMODO_DATABASE_PASSWORD=REPLACE_WITH_PASSWORD
POSTGRES_USER=${KOMODO_DATABASE_USERNAME}
POSTGRES_PASSWORD=${KOMODO_DATABASE_PASSWORD}
FERRETDB_POSTGRESQL_URL=postgres://${POSTGRES_USER}:${POSTGRES_PASSWORD}@komodo-postgres:5432/postgres


KOMODO_INIT_ADMIN_USERNAME=admin
KOMODO_INIT_ADMIN_PASSWORD=REPLACE_WITH_PASSWORD
KOMODO_JWT_SECRET=REPLACE_WITH_SECRET
KOMODO_WEBHOOK_SECRET=REPLACE_WITH_SECRET
```

## Troubleshooting

Run `docker compose -p komodo logs --tail=200 komodo-postgres komodo-ferretdb komodo`. Check that PostgreSQL and FerretDB use matching credentials. Keep `-p komodo` and the named volumes when recreating containers.
