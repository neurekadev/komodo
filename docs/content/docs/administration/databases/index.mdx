Komodo stores resource configuration, users, audit records, and system state in a MongoDB-compatible database.

## Choose a database

- [MongoDB](/administration/databases/mongodb) is the recommended path and has the smallest deployment.
- [FerretDB](/administration/databases/ferretdb) uses PostgreSQL with DocumentDB compatibility. Use it when the host cannot run current MongoDB images or when PostgreSQL is an operational requirement.

Changing database engines for an existing installation is a migration, not a Compose-only edit. Back up and verify the database before replacing services.
