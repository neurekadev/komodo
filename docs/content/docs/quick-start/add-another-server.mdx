---
title: Add Another Server
description: Connect another Docker host to Core using Periphery.
---


The main installation already manages its local Docker host. Use this guide for each additional host. You need Docker Engine with Compose there, administrator access to Komodo, and an HTTPS Core address reachable from the new host.

## Connect the server

1. In Komodo, open **Settings → Onboarding**, create an onboarding key, and copy it. It is shown only once.
2. On the new host, run `mkdir -p komodo-periphery && cd komodo-periphery` and save the examples below as `compose.yaml` and `.env`.
3. Set your Core address, the new Server name, and onboarding key in `.env`. Run `chmod 600 .env`.
4. Start Periphery:

   ```bash
   docker compose -p komodo config --quiet
   docker compose -p komodo up -d
   ```

5. In **Servers**, select the new Server and confirm **OK**.
6. Copy the Server ID from the new Server resource, replace the name in `PERIPHERY_CONNECT_AS` with that ID, and remove `PERIPHERY_ONBOARDING_KEY` from `.env`. Run `docker compose -p komodo up -d --force-recreate`, then disable the key in Komodo when no other server needs it. Using the ID keeps the connection stable if the Server is renamed.

Periphery controls this Docker host and its volumes. Keep its persistent data volume when recreating the container; it contains its identity and managed files.

## compose.yaml

```yaml title="compose.yaml"
services:
  komodo-periphery:
    image: ghcr.io/neurekadev/komodo-periphery:${COMPOSE_KOMODO_IMAGE_TAG:-3}
    container_name: komodo-periphery
    env_file: [.env]
    networks: [komodo-periphery]
    volumes:
      - data:/data
      - /var/run/docker.sock:/var/run/docker.sock
      - ${PERIPHERY_DOCKER_VOLUME_ROOT:-/var/lib/docker/volumes}:${PERIPHERY_DOCKER_VOLUME_ROOT:-/var/lib/docker/volumes}
      - /proc:/proc
    restart: unless-stopped
    init: true
    command: [periphery-compose]

networks:
  komodo-periphery:
    name: komodo-periphery

volumes:
  data:
```

## .env

```dotenv title=".env"
PERIPHERY_CORE_ADDRESS=https://REPLACE_WITH_HOST
PERIPHERY_CONNECT_AS=my-server

PERIPHERY_ONBOARDING_KEY=REPLACE_WITH_API_KEY
```

## Troubleshooting

Run `docker compose -p komodo logs --tail=100 komodo-periphery`. Check that Core is reachable, its TLS certificate is trusted, and `docker ps` works on the host. For rootless Docker or a custom Docker directory, follow [Container Deployment](/administration/container-deployment#custom-docker-paths).
